# Security policy

The current `main` branch is the only supported version of this course project. There are no maintained release branches.

Please do not put credentials, exploit details, or other sensitive information in a public issue. Use GitHub's private vulnerability reporting if it is available for this repository. Otherwise, contact me through the NYU course platform.

I'll reproduce a reported problem, prepare a fix in a pull request, and describe the security update when the fix is merged.
